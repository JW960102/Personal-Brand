사이트 보기
01 — OVERVIEW

A brand experience, not a product list.

제품 판매몰이던 일광전구 웹사이트를 브랜드 경험 중심의 인터랙티브 웹으로 리뉴얼했습니다. 저는 UI 디자인과 프론트엔드 구현, 사용성 평가를 맡았습니다. 브랜드의 인상을 화면 전반에서 일관되게 전달하는 것을 목표로 했습니다.

Challenge
& Solution

Consistency had to be designed into the team.

첫 팀 프로젝트에서는 각자 디자인을 잘해도 구현 단계에서 스타일의 통일성이 쉽게 무너졌습니다. 내비게이션 미동작, 가로 스크롤, 모바일 가독성처럼 사용 흐름을 막는 문제도 1차 점검에서 확인했습니다.

닐슨의 10대 휴리스틱을 기준으로 1차 점검, 개선, 2차 재점검을 반복했습니다. 동시에 Git 협업 가이드를 만들어 팀의 작업 방식을 합의하고, 타이포·컬러·스페이싱을 디자인 토큰으로 정리해 같은 기준으로 구현할 수 있게 했습니다.

반응형 레이아웃은 max-width 컨테이너 기준을 다시 세워 안정화했습니다. 디자인을 만드는 일과 팀이 같은 결과물을 내는 일은 다르다는 것을 배운 작업입니다.

What
I Learned

A shared rule can make a team move faster.

처음 해 본 Git 협업과 팀 단위 구현에서, 문제를 개인의 숙련도로만 해결하려 하면 반복해서 같은 비용이 생긴다는 것을 알았습니다.

협업 가이드와 디자인 토큰은 단순한 문서가 아니라 팀의 판단 기준이었습니다. 이 경험을 통해 협업에서 생기는 이슈를 발견하고, 모두가 쓸 수 있는 방식으로 해결하는 법을 익혔습니다.
