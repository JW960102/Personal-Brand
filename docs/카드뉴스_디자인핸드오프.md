# 카드뉴스 — 디자인 핸드오프 (김종욱 디자인 → Claude 구현)

> 2026-07-27. **김종욱이 이 문서로 카드 템플릿을 디자인 → Claude가 실측대로 React 구현 → 엔진에 꽂음.**
> 엔진(생성 플로우·카테고리·undo·내보내기·덱·변형)은 이미 완성 = 유지. **바꾸는 건 "카드 템플릿 비주얼"뿐.**
> 리서치 원문: `카드뉴스_리서치_스펙.md`, `카드뉴스_패턴카탈로그.md`. 이 문서는 그 요약 + 디자인 지침 + 넘길 포맷.

---

## 0. 캔버스 규격
- **1080 × 1350 px (4:5)** 권장 — 인스타 세로 최대 노출. (1:1 원하면 1080×1080, 말해줘)
- 안전 여백(권장): 바깥 6~8% (≈ 상하좌우 70~100px)
- 내보내기는 이 규격으로 자동 (엔진 완료).

## 1. 폰트 자산 (이미 로드됨 — 이 안에서 쓰면 바로 구현)
- **General Sans** (영문 디스플레이/헤드라인) — Fontshare
- **Newsreader** (영문 세리프/에디토리얼) — Google
- **Pretendard** (한글 전부, 본문) — jsdelivr
- ※ 다른 폰트(예: 둥근 고딕 잘난체류) 쓰고 싶으면 **폰트명 + 라이선스 확인**해서 알려줘 → 추가.

## 3. 분류 기준 & 6개 카테고리
**기준**: 콘텐츠 목적(정보/감성/홍보) × 비주얼 무드. 서로 구별 + 테마 매핑되게 6묶음.

| 카테고리 | 무드 | 테마 | 자주 쓰는 카드 | 톤 |
|---|---|---|---|---|
| 미니멀 에디토리얼 | 절제·여백 | White·Oat | 표지·본문·인용 | 담백·선언형 |
| 감성 에세이 | 스토리·세리프 | Cream·Blush·Lavender | 표지·본문·인용·한줄 | 서정·1인칭 |
| 비즈니스 리포트 | 정돈·데이터 | Sky·White | 목차·리스트·통계·CTA | 명확·불릿 |
| 프레시 내추럴 | 친근·건강 | Sage | 팁·리스트·본문 | 친근·실용 |
| 볼드 트렌디 | Z세대·강조 | Dark | 표지·한줄강조·통계 | 짧고 강한 훅 |
| 브랜드 프로모션 | 이벤트·CTA | 임의 | 혜택·CTA·표지 | 행동유도 |
→ 카테고리 재편·추가·삭제 자유.

## 4. 공통 원칙 (리서치)
- **시퀀스**: 표지(훅) → 밸류 → CTA / 5~10장 / 강한 포인트 3장 안에
- **표지 훅**: 헤드라인 5~8단어(가장 큼) + 대비 + 궁금증
- **폰트 1~2개**, 계층(display/heading/body) 명확, **여백 넉넉**
- **색 2~3개**, 본문 그레이, 포인트색 통일
- ★ "예쁜 그래픽보다 시퀀스" — 근데 **네가 조판을 예쁘게 = 여기가 퀄리티**

## 5. 필요한 카드 템플릿 (우선순위)
꼭 필요(코어): **표지 / 본문 / 리스트 / 통계 / 인용 / CTA(마무리)**
정갈형 강화: **번호그리드 / 체크리스트 / 목차 / 스텝**
추가(여력): 한줄강조 / VS비교 / Q&A / 이미지그리드 / 아이콘로우
→ 각 템플릿마다 **변형 2~3개**(정렬·배치) 있으면 시안 다양성 ↑ (선택).

## 6. ★ Claude에게 넘길 "실측 스펙" 포맷
outpost 실측했던 것처럼, 각 템플릿을 이 형식으로 주면 **픽셀 그대로 구현**함.
카드 = 1080×1350 기준 절대 px로 적어줘.

**템플릿 예시: 표지(cover) — variant A**
```
[캔버스] 1080×1350, 배경 = 테마 bg
[여백] 좌우 80 / 상 90 / 하 90
[요소]
· eyebrow 라벨  : 상단, x=80 y=110, Pretendard 500, 28px, 색 accent, letter-spacing 0.12em, 대문자
· 메인 타이틀   : 하단정렬, x=80, 폭 920, General Sans 600, 132px, line-height 1.0, 자간 -0.03em, 색 ink
· 서브 카피     : 타이틀 아래 24px, Newsreader 400, 40px, 색 sub
[정렬] 좌측, 콘텐츠 하단 배치
```
이런 식으로 **요소별: 위치(x,y 또는 정렬)·크기·폰트(패밀리/굵기/px/행간/자간)·색(테마 토큰명)** 만 주면 돼.
피그마면 **오토레이아웃 + 텍스트 스타일 값**을 그대로 읽어서 줘도 되고, 스샷+치수 메모도 OK.

## 7. 작업 흐름
1. 김종욱: 위 포맷으로 템플릿 디자인 (한 번에 다 말고, **표지부터 1~2개씩** 줘도 됨)
2. Claude: 실측대로 React 컴포넌트 구현 + 기존 엔진(생성/편집/내보내기)에 연결
3. 반복 → 템플릿 세트 완성
→ 엔진·플로우는 그대로, 껍데기만 네 퀄리티로 교체.
