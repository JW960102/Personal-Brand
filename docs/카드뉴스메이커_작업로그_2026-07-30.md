## 1. 방향 전환 (핵심)

**기존(폐기):** 디자인 팩(민트·스카이)을 손으로 그려두고, 고른 걸 그대로 재생 / 순서만 조합.
→ 문제: **미리캔버스·망고보드와 다를 게 없음.** "템플릿 라이브러리"는 차별점이 아님.

**새 방향(확정):** **생성 레이아웃 엔진.**
- 사용자가 정하는 건 **[장수 · 스타일 · 레이아웃 타입]** 뿐
- 앱이 **텍스트박스·표·그래프의 위치·크기를 "계산해서" 생성** (손으로 그리는 게 아님)
- 그 위에서 사용자가 **드래그로 직접 다듬음** → 완전 자동 아님, **"뼈대만 잡아주는 무료 틀"**

**AI 없이 되는 이유:** 레이아웃 생성 = 절차적 배치(그리드·타입스케일·아키타입·텍스트 피팅). 위치 계산 자체엔 AI가 필요 없음. AI는 "주제만 넣으면 카피까지 써주는" 편의 기능일 뿐(선택).

## 2. 포지셔닝 / 인터뷰 서사

마케팅팀이 카드뉴스를 급히 만들어야 할 때, 디자인팀·AI를 기다리는 **시간을 줄여주는 무료 도구**.
> "누르면 뼈대가 생성되고, 만든 게 백엔드에 쌓입니다. 자료가 축적되며 점점 진짜 앱이 됩니다. 지금 혼자선 불가능하지만, 뽑아주시면 천천히 완성해 회사에 도움이 되는 앱으로 키우겠습니다."

**자가 부트스트랩 플라이휠:** 김종욱이 피그마 대신 이 앱에서 만들고 저장 → 데이터가 스스로 쌓임 → 나중에 그 데이터를 수치화·프롬프트화해 엔진을 강화.

## 3. 이번 세션 구현 (로컬)

| 기능 | 설명 | 주요 파일 |
|---|---|---|
| **생성 엔진** | [장수·스타일·레이아웃타입] → 요소 좌표 계산 → 카드덱 | `data/styles.js` `data/archetypes.js` `lib/generateScaffold.js` |
| **렌더러** | 요소(text/shape/image/bar)를 설계 px→cqw로 배치 | `components/Stage.jsx` |
| **드래그 작업창** | 요소 선택·드래그 이동·리사이즈 + 인스펙터 | `components/GenWorkspace.jsx` |
| **undo/redo** | Ctrl+Z / Ctrl+Shift+Z, 드래그=1스텝(태그 묶기) | `lib/useHistory.js` |
| **텍스트 자동 피팅** | 박스(w×h) 넘치면 글자 크기 자동 축소(이진탐색) | `Stage.jsx`의 FitText |
| **이미지 실제 삽입** | 로컬 파일→dataURL→카드(cover/contain), 업로드 없음 | `GenWorkspace` + `Stage` |
| **저장 / 불러오기** | localStorage 저장(id 기준 덮어쓰기) + 설정화면 썸네일 목록→편집 복귀 | `lib/store.js` `components/GenSetup.jsx` |
| **카드 순서변경** | 덱 썸네일 드래그로 재정렬 | `GenWorkspace.jsx` |
| **전체 PNG** | 숨김 1080 실측 스테이지로 카드별 순차 캡처 | `GenWorkspace.jsx` `lib/exportCard.js` |

**로컬 루프 완결:** 입력 → 뼈대 자동 생성 → 편집 → 저장/불러오기 → PNG 출력.

## 4. 아키텍처

**데이터 모델**
```
deck = {
  id, styleId, canvas: { w:1080, h:1350, aspect:'4:5' },
  cards: [ { id, archetype, elements: [ {id, type, x, y, w, h, ...} ] } ]
}
```
- 요소 좌표 = 설계 px(1080×1350) → 렌더 시 cqw 환산(표시 크기에 자동 스케일)
- 색 = `var(--card-*)` 토큰. **스타일=룩 / 아키타입=위치** 분리
- 요소 타입: `text`(font/size/weight/align/valign/lh/content) · `shape`(fill/radius) · `image`(src/fit) · `bar`(items/color)

**아키타입(레이아웃 타입)** = 좌표 계산 함수: `title` `card` `table` `bar` `closing`
**스타일 프리셋:** 판매 · 통계 · 뉴스 (색·폰트 토큰)

**진입/보존 라우트** (App.jsx)
- 메인 = `GenApp` (생성 엔진)
- `?legacy` = 구 flex 흐름 / `?packs` = 팩 재조합 실험 / `?pack=` = 팩 직접 (전부 보존)
