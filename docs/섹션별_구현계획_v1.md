## 공통 시스템

**레퍼런스**: 메인 outpost.design / 서브 fluid.glass / About 화법 adcker.com
**아트보드**: 1920×1080 기준 → 구현 시 `clamp()`+vw로 반응형 변환
**폰트**: 로고 DM Serif Display Italic / 디스플레이·본문 Pretendard / (한글 서체 통일 여부 미정)
**컬러**: 흑백 미니멀 (배경 white·텍스트 black). **포인트 컬러는 프로젝트 이미지 안쪽에서만**
**좌측 기준선**: 130px (로고만 30px)
**헤더**: 오버레이 바 117px, 로고 "JW portfolio" 좌 / "Menu" 우 — 전 페이지 공통 고정

**디자인 결정 원칙**: 클릭 인터랙션 → 스크롤 인터랙션으로 전환 (방문자=면접관, 체류 짧음 → 클릭은 노출 안 됨). 이 판단 자체가 케이스 스터디 소재
