## 완료된 것

### 폰트 시스템 (2폰트 확정)
- `--f-serif` = DM Serif Display Italic → **로고 전용**
- `--f-sans` = Pretendard → **그 외 전부** (Arial·Noto Sans KR 폐기)
- 주의: `<button>`은 폰트 상속 안 됨 → Menu·챗봇 버튼에 font-family 명시함

### 01. Hero 섹션 (시안 949:580 기반, 실측 반영)
- 카피 **DESIGN / DEVELOP / DELIVERED** 계단 배치
  - 좌표: DESIGN(좌 13.75vw 들여쓰기) / DEVELOP(기준) / DELIVERED(5.57vw) — 시안 비율과 픽셀 일치 검증됨
  - 폰트 200px(10.4167vw clamp), 행간 0.865
- 헤더: 반투명 바 rgba(0,0,0,0.4) + 로고(DM Serif Italic) + Menu(Pretendard)
- 스크롤 인디케이터(그라데이션 바 + Scroll Down) — 흐르는 빛 애니메이션
- 챗봇 FAB(우하단, UI 자리만)

### Hero 인터랙션 (GSAP)
- 헤더 드롭 등장
- 타이틀 3줄 마스크 리빌 (아래→위 밀려 올라옴, 0.12s stagger, power4)

### Hero 배경 3D JW 오브제 (three.js) — STEP 3 (유리, 임시 확정) ✅
> 진행: STEP 1(형태) → STEP 2(크롬 금속) → **STEP 3(유리 조형물)**. 아래가 현재 상태.

**STEP 2 (크롬 금속) — 폐기 사유:** 흰 금속이 환경을 불투명 반사 → 명암 대비가 커서
히어로 텍스트를 읽는 데 거슬림. 레퍼런스(outpost)는 유리 투과 재질이라 저대비.

**STEP 3 = B안 (유리 투과 + 색수차 후처리):**
- 파일: `js/hero3d.js`
- 렌더: `WebGLRenderer({antialias})` **불투명 흰 배경** `setClearColor(0xffffff,1)`
  → 유리가 굴절할 흰 배경 확보 + EffectComposer 알파 문제 없음 (페이지색 #fff와 동일해 시각적으론 투명)
- ACESFilmic 톤매핑, exposure 1.0
- 환경맵: `images/studio.hdr` (스튜디오 HDRI) → PMREM → scene.environment
- **후처리:** EffectComposer + RenderPass + **RGBShiftShader(색수차)** — amount 0.0016, angle 0.6
  (빈 영역은 순백이라 유리 실루엣 경계에서만 미세 무지개빛)
- 회전: Y축 `dt * 0.22` rad/s (천천히)

**현재 확정 파라미터 (2026-07-27):**
| 구분 | 파라미터 | 값 |
|---|---|---|
| Geometry | size / height·depth / bevelThickness·Size / bevelSegments | 78 / **4** / **1** / 10 |
| Material (MeshPhysicalMaterial) | transmission | 1.0 |
| | thickness (굴절 강도, geometry 깊이와 별개) | **10** |
| | ior | **1.3** |
| | roughness | 0.06 |
| | envMapIntensity | **0.8** |
| | clearcoat / clearcoatRoughness | 1.0 / 0.1 |

**튜닝 히스토리 (이번 세션):**
- 두께: height/depth 20 → 8 → **4** (사용자: "2배 얇게"), 베벨 4/3 → 2/2 → **1/1**
- 투명도: thickness 24→**10**, ior 1.5→**1.3**, envMapIntensity 1.4→**0.8** (사용자: "더 투명하게")
- ⚠️ 핵심: **geometry 깊이(height/depth)와 굴절 강도(material.thickness)는 분리됨.**
  글자를 얇게 해도 thickness로 굴절 유지 가능.

**나중에 더 손볼 여지 (사용자: "일단 이대로, 나중에 수정"):**
- 더 유령처럼 → envMapIntensity 0.4, clearcoat 0.5
- 존재감 회복 → thickness / envMapIntensity 상향
- (원한다면) outpost식 GLB 유리 모델로 교체 — 현재는 three.js 표준 TextGeometry로 대체 구현
