# 카드뉴스 생성기 — 리서치 스펙 (프롬프트화 재료)

> 2026-07-27. 웹 리서치 종합 → 생성 엔진에 넣을 "재료". 6개 테마 카테고리 기준.
> 설계 근거: `카드뉴스메이커_설계.md` 8~9장. 이 문서 = 엔진 데이터의 출처.

---

## A. 공통 원칙 (모든 카테고리 적용)

**시퀀스 (레시피의 뼈대)**
- 구조 = **표지(훅) → 밸류 슬라이드 → CTA(마무리)**
- 장수: 보통 **5~10장** (제품·소개형 5~8 / 교육·정보형 8~12)
- 가장 강한 포인트는 **3번째 슬라이드 안에** 배치
- 본문 = **한 장 = 한 메시지**
- ★ "예쁜 그래픽보다 **시퀀스 설계**가 성패를 가른다" (우리 철학과 일치)

**표지(훅) 공식**
- 훅 헤드라인 **5~8단어**(가장 큰 텍스트) + 시각 대비 + 궁금증 유발(질문/통계/부분노출)

**타이포**
- 폰트 **1~2개만**. 고딕(산세리프)=정보·전문 / 명조(세리프)=감성·스토리. 장식체는 타이틀만
- 계층: **display / heading / body** 명확히. 큰 글씨 + 충분한 여백

**색**
- 페이지당 **2~3색**. 본문은 그레이 계열, **포인트색 하나로 통일**. 강조는 최소화

---

## B. 카드(슬라이드) 종류 카탈로그

| 종류 | 현재 앱 | 역할 |
|---|---|---|
| 표지 cover | ✅ (훅 강화 필요) | 스크롤 정지 + 궁금증 |
| 목차 index | ❌ **신규** | 8장+ 정보형에서 흐름 안내 |
| 본문 body | ✅ | 한 장 한 메시지 |
| 리스트 list | ✅ | 팁·항목 나열 |
| 통계 stat | ✅ (강화) | 숫자 임팩트 |
| 인용 quote | ✅ (강화) | 감성·권위 |
| 한줄강조 punch | ❌ **신규** | 볼드형 대형 한 문장 |
| 마무리 cta | ❌ **신규** | 요약·행동유도 ("이 장만 저장해도 가치 있게") |

→ **신규 3종(index·punch·cta) 추가**가 프롬프트화 1순위.

## C. 6개 카테고리 스펙 (각 5축)

### 1. 미니멀 에디토리얼
- **색**: 배경 White·Oat / 잉크 먹·에스프레소 / 강조 무채색(먹). 2색
- **폰트**: 디스플레이=산세리프(General Sans) + 본문=세리프(Newsreader)
- **레이아웃**: 좌측정렬·큰 여백·비대칭, 작은 uppercase 라벨
- **레시피**: `cover → body → quote → body → cta`
- **카피 톤**: 담백·선언형, 짧은 문장

### 2. 감성 에세이
- **색**: 배경 Cream·Blush·Lavender / 잉크 딥톤 / 강조 포인트 파스텔
- **폰트**: 세리프 중심(Newsreader) 디스플레이+본문 (명조 감성)
- **레이아웃**: 중앙정렬 여지·넉넉한 행간·부드러움
- **레시피**: `cover → body → quote → body → cta`
- **카피 톤**: 서정적·1인칭·여운

### 3. 비즈니스 리포트
- **색**: 배경 Sky·White / 잉크 네이비·그레이 / 강조 블루
- **폰트**: 산세리프 정돈(General Sans 디스플레이+본문)
- **레이아웃**: 반듯한 그리드·번호·정렬
- **레시피**: `cover → index → list → stat → cta`
- **카피 톤**: 명확·데이터·불릿

### 4. 프레시 내추럴
- **색**: 배경 Sage·Mint / 잉크 딥그린 / 강조 그린
- **폰트**: 부드러운 산세리프
- **레이아웃**: 여백 넉넉·라운드 느낌·팁/체크
- **레시피**: `cover → list → body → stat → cta`
- **카피 톤**: 친근·실용·따뜻

### 5. 볼드 트렌디
- **색**: 배경 Dark + 형광 강조(#d6ff1e) / 고대비
- **폰트**: 초대형 산세리프·강한 굵기 대비
- **레이아웃**: 꽉 찬 타이포·풀블리드·중앙
- **레시피**: `cover → punch → stat → punch → cta`
- **카피 톤**: 짧고 강한 훅·구어체

### 6. 브랜드 프로모션
- **색**: accent 강한 임의 테마 / 브랜드색 강조
- **폰트**: 굵은 산세리프
- **레이아웃**: 혜택·CTA 강조, 버튼감
- **레시피**: `cover → list → stat → cta`
- **카피 톤**: 행동유도·혜택·(적당한) 긴급감
