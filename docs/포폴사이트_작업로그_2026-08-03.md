## 4. 인터랙션 (핵심)

### 최초 진입 인트로 (1회, 반복 없음)
`.js`(head 인라인 스크립트) → `.intro-play`(main.js) 로 CSS 타임라인 실행.
| 시점 | 동작 |
|---|---|
| 0.0s | 헤더 하강 (0.5s) |
| 0.5s | **3D 오브제 0→1 확대** (1.1s, hero3d.js `INTRO_DELAY/INTRO_DUR`) |
| 2.0s | THINK 상승 + 스튜디오·화살표·십자 페이드인 |
| 2.3s | MAKE & + **영상 동시 등장 & 재생 시작** |
| 2.6s | DELIVER |
- 헤드라인/영상은 **줄 마스크(overflow) + 안쪽 요소 translateY(115%)** 로 "땅에서 솟는" 등장
- `introDone`(3.6s) 전까지 스크롤 로직이 헤더·화살표를 건드리지 않음

### ⚠ CSS 지연은 반드시 `--delay` 커스텀 속성으로
별도 규칙에 `transition-delay`를 쓰면 **선택자 우선순위에 밀려 단축 속성의 0s에 덮여 무시됨.**
(실제로 히어로 텍스트가 지연 없이 즉시 나오는 버그로 이어졌음)
```css
.hw-think { --delay: 2.0s; }
.intro-play .hw > span { transition: transform .9s var(--ease) var(--delay, 0s); }
```

### 인트로 카피 (모두가 모든 것을~)
- 5줄 각각 마스크, **섹션이 화면 1/3 진입 시** `.reveal` 부여 → 0.15s 간격 순차 상승, **1회만**
- 판정은 `getBoundingClientRect()` (무대 스케일이 이미 반영된 화면 좌표라 `--sf` 보정 불필요)
- About me 버튼·MY LATEST WORK 는 **의도적으로 제외**

### 프로젝트 이미지·기여도 부유 (스크롤 연동, 양방향)
- 대상: `.proj > img, .proj > figure, .proj > .ph-meta` (12개)
- `FLOAT_OFFSET 90`(캔버스 px) 아래에 떠 있다가 안착. `FLOAT_SETTLE 0.30` = 요소 상단이 화면 높이 30% 지점에 오면 제자리 (**낮출수록 늦게 도착**)
- 이징 **easeInOutCubic** (pow(1-p,3)은 전반에 87% 몰려 "너무 빨리 도착" 느낌 → 폐기)
- 성능: 위치는 `measureFloats()`로 **fit() 때만 측정·캐시**, 스크롤 중엔 산술 계산만

### 버튼 채움 (`.btn-fill` 공통)
- `::before`가 `scaleX(0)→1`, `transform-origin: left` → **왼쪽부터 차오름**, 글자 흰색 전환
- 적용: About me / VIEW MORE PROJECTS / Contact(다크 배경이라 흰색 채움+검정 글자)
- 텍스트는 `<span>`으로 감싸 채움 레이어 위에 오게 함

### 십자(+) 메뉴 버튼
- **fixed z-999**(무대 밖) — 전 구간 화면 고정, 클릭 시 메뉴 예정
- 호버: 세로획 위→아래 / 가로획 좌→우 그라데이션 이동 = **좌상단→우하단 대각 채움**

## 6. 아키텍처 요약 (변동 없음)
```
#hero3d (fixed, z0)          ← 3D 배경
.stage-wrap (z1)
 ├ #clamp1 > #stage1         ← 히어로~인트로 (scale --sf)
 ├ .values-track > sticky    ← 가치 섹션 (네이티브 sticky 핀)
 └ #clamp2 > #stage2         ← 프로젝트~푸터
#heroVideo (fixed, z90) / .hero-mark (fixed, z999)
```
- ⚠ **조상에 `overflow` 금지** — sticky가 죽음
- transform은 레이아웃 높이를 안 줄이므로 clamp 높이를 JS가 보정
