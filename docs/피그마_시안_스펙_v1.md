- 커스텀 lerp 관성 스크롤 (Lenis/Locomotive 아님, 직접 구현, ease power3.inout)
- Nuxt.js(Vue) 기반

**우리 방침 (A안 채택 — "느슨하게"):**
- ✅ **GSAP + ScrollTrigger + SplitText 도입** (CDN). 김종욱 이력서에 GSAP 있음 → 정당
  - SplitText·CustomEase는 2025년부터 무료 전환 → 사용 가능
- ❌ **WebGL/Three.js 유리효과 안 함** (시간·무게 대비 비효율, 안 넣어도 무방)
- 인터랙션 패턴은 참고하되 콘텐츠(글자·이미지·컬러)는 김종욱 것 → 자연히 다른 사이트
- 순수 CSS 키프레임(구 Hero 방식)은 GSAP로 교체

**주의**: 이 세션 프리뷰가 애니메이션을 일시정지(documentHidden)시켜 Claude가 재생 관찰 불가 → 코드 검증만, 최종 눈 확인은 김종욱 브라우저
