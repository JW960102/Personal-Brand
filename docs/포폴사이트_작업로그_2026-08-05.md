## 4. 핵심 인터랙션 — 히어로 사진이 01 슬롯으로 내려앉음

**처음 만든 것:** 히어로에 큰 사진, 01 OVERVIEW 에 같은 사진 → 중복이라 보기 나빴다.
**해결:** 사진을 **하나만** 두고 스크롤에 따라 히어로 자리 → 01 슬롯으로 **이동·축소**시킨다.

```js
var CH_BOX   = { x:647, y:633, w:876, h:1282 };  // 히어로에서의 자리 (캔버스 px)
var CH_SETTLE = 0.2;   // 슬롯 상단이 화면 20% 지점에 오면 이동 완료
var CH_HOLD   = 0.9;   // '사이트 보기'가 화면 90% 지점까지 올라오면 이동 시작
```

- 시작·끝 좌표를 **둘 다 `문서좌표 − 스크롤`** 로 계산 → 도착(p=1) 후에는 슬롯과 함께
  자연스럽게 스크롤된다. **고정 해제 처리를 따로 안 해도 된다**는 게 이 방식의 핵심.
- 이징은 `easeInOutCubic`.
- 슬롯 위치는 `measureSlot()` 이 `fit()` 때마다 다시 잰다 (리사이즈 대응).

### ⚠️ 사진은 무대 **밖**에 둔다
`position: fixed` 는 `transform: scale()` 된 조상 안에서 깨진다 (메인에서 이미 세 번 겪음).
`#chPhoto` 는 `.stage-wrap` 바깥, `#heroVideo`·`.footer-reveal` 과 같은 층에 둔다.

### 시작 타이밍 조정 이력
| 시도 | 문제 |
|---|---|
| 히어로 진입 즉시 | **너무 빨라서** 제목·메타를 읽기도 전에 사진이 도망감 |
| `CH_HOLD = 0.9` | '사이트 보기' 버튼까지 다 본 뒤 움직임 ✅ |

## 5. 본문 레이아웃 — 두 번의 방향 전환

### 1차: 사진이 화면을 꽉 채움 → **"숨 막힌다"**
→ 사진을 세로로 길게(4:5) 만들고 한쪽으로 몰고, 제목·본문을 반대편에 붙였다.

```css
.case-row {
  grid-template-columns: 1fr 712px;   /* 882 + 66 + 712 = 1660 → 거터 양끝(130·1790)에 딱 붙음 */
  gap: 66px;
  align-items: stretch;               /* 글 칸이 사진 높이만큼 늘어나야 하단정렬이 성립 */
}
.case-text { display: flex; flex-direction: column; }
.case-text .case-en { margin-top: auto; }   /* 번호는 위, 제목·본문은 아래 */
```
- 번호는 **사진 상단**, 제목·한글 카피는 **사진 하단**에 맞춤.

### ⚠️ 2차: 이 비대칭을 02~05 에도 적용했다가 되돌림
"난 이미지로 보여준 섹션 **만** 저렇게 하란 거였는데" → **01 오버뷰에만** 적용.
**교훈: 한 섹션에 대한 지시를 전체 규칙으로 확대 해석하지 말 것.**

### 3차: 02~05 를 **2개로 통합** + 레퍼런스형 2단
"02, 03, 04 너무 잘게 쪼갰다" → `어려웠던 점과 해결` / `무엇을 배웠는가` 2개로.

```css
.case-sec {
  grid-template-columns: 650px minmax(0, 890px);  /* 좌 라벨 / 우 본문 */
  margin-top: 200px; padding-bottom: 140px;
  border-bottom: 1px solid var(--c-line);
}
.case-h    { font-size: var(--fs-56); text-transform: uppercase; }
.case-lead { font-size: var(--fs-32); color: var(--c-ink); }  /* 영문 리드 */
.case-body p { font-size: var(--fs-24); color: var(--c-ink-60); word-break: keep-all; }
```

- 영문 카피를 **버리지 않고 리드 문장(32px)** 으로 본문 맨 위에 남겼다.
  레퍼런스는 라벨+본문뿐이지만, 그 영문 한 줄이 이 사이트의 목소리라 없애면 밋밋해진다.
- 문단은 `<br><br>` 이 아니라 **진짜 `<p>` 로 분리** → 간격이 일정해짐.
- `.case-body > .case-card { margin-top: 72px; }` — 기여도 카드가 본문에 붙지 않게.
- `.case-next` 는 `border-top` 을 **제거** — 바로 위 `.case-sec` 의 아래 선과 겹쳐 이중선이 됨.

## 10. Works 카드 인터랙션 추가 (2026-08-06)

`works.html`의 프로젝트 카드에 가벼운 진입·호버 인터랙션을 추가했다.

- 카드가 화면에 처음 들어올 때만 `24px` 아래에서 부드럽게 올라와 표시.
  - `IntersectionObserver`로 구현.
  - 한 번 표시된 카드는 다시 스크롤해도 반복 재생하지 않음.
  - 같은 행의 두 카드는 `90ms` 간격으로 순차 등장.
- 호버 시 이미지 `4%` 확대.
- 프로젝트명은 위로 `5px` 이동하고, 제목 뒤의 `↗` 화살표는 우상단으로 이동.

## 10. 마감 전 전수 점검 (2026-08-05)

5개 페이지(`index` / `works` / `work-wrun` / `work-ilkw` / `work-goi`)의
링크·앵커·중복 id·이미지 참조·JS 문법을 기계적으로 훑고 발견된 것을 고쳤다.

### 10-1. 🔴 `#about` 앵커가 존재하지 않았음 (링크 11개가 죽어 있었음)

GNB·푸터·인트로의 "About me" 버튼이 모두 `#about` 을 가리키는데
**문서 어디에도 `id="about"` 이 없었다.** 클릭해도 아무 일도 안 일어난다.

- `index.html` 의 values 트랙(`What i'm made OF`) 바로 앞에 앵커를 신설.
  `#valuesTrack` 은 id 가 이미 있어 **높이 0 의 별도 앵커 요소**를 둔다.
  ```html
  <div class="anchor" id="about"></div>
  ```
- `.anchor { height: 0; scroll-margin-top: calc(90px * var(--sf, 1)); }`
  → 고정 헤더에 제목이 가리지 않게.
- **인트로 안의 "About me" 버튼이 자기 자신을 가리키던 문제도 같이 해결** —
  이제 인트로 선언문 → 가치 섹션으로 내려간다.

⚠️ **About 을 인트로로 바꾸고 싶으면** `.intro` 로 앵커를 옮기면 된다 (한 줄).

### 10-2. 🔴 서브페이지→메인 앵커 이동이 엉뚱한 곳에 서던 문제

`index.html#about` 로 들어오면 브라우저의 앵커 점프가
**`fit()` 이 클램프 높이를 정하기 전에** 일어난다. `transform: scale()` 무대는
스크립트가 높이를 넣어 주기 전까지 문서 길이가 달라 위치가 어긋난다.

→ `js/main.js` 에서 `load` 이후 한 번 더 목적지로 맞춘다.
```js
if (location.hash) {
  window.addEventListener('load', function () {
    var target;
    try { target = document.querySelector(location.hash); } catch (e) { return; }
    if (target) target.scrollIntoView();
  });
}
```

### 10-3. 🔴 푸터 오타 `CONNET WHIT ME` → `CONNECT WITH ME`

`index.html` 과 `work-wrun.html` 에 남아 있었다 (ILKW·GOI 는 이미 고쳐져 있었음).
**면접관이 정독하는 페이지의 영문 오타** 라 우선순위를 높게 봤다.

### 10-4. 🟡 `works.html` 에만 챗봇·맨위로 버튼이 없었음

GNB 의 정식 목적지인데 `.fab-stack` · `.chat-panel` · `js/chat.js` 가 통째로 빠져 있었다.
챗봇은 이 사이트의 시그니처라 **전 페이지에 있어야 일관된다.** 다른 페이지와 동일하게 추가.
칩 문구만 목록 페이지에 맞게 바꿈 (`어떤 프로젝트를 진행했습니까?` / `어떤 기술을 다룰 수 있습니까?`).
