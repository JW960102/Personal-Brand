# 카드뉴스 패턴 카탈로그 — 정갈·규격형 (큐레이션용)

> 2026-07-27. 김종욱 제공 예시(망고보드, 수영장 에티켓 등) + 웹 리서치 종합.
> 목적: **재현 가능한 패턴만** 추려 엔진 재료화. 김종욱이 이 목록에서 "넣자/빼자" 큐레이션.
> ⚠️ **스코프 아웃**: AI 일러스트 범벅형(예: 복고풍 경제 시사만평)은 **제외** — 우리 엔진으로 생성 불가 + 규격화 안 됨.
> 재현 표기: ✅ CSS만으로 완전 재현 / ⚠️ 작은 아이콘·이미지 필요 / 🟡 부분(배경만/텍스트만)

## A. "정갈·규격형" 스타일 DNA (공통 요소)
예시 2·3·4에서 반복되는 재현 가능한 규칙:
- **단색 컬러블록 / 은은한 패턴 배경** + **흰색 라운드 카드** 위에 콘텐츠
- **번호 배지**(원형·포인트색), **필/뱃지 라벨**(라운드 사각), **넉넉한 라운드 코너**, **소프트 섀도**, 가끔 **점선 보더**
- **볼드 라운드 고딕**(친근) 타이틀 / 중간 굵기 라벨
- 색 **2~3개 + 포인트색 통일** (예: 블루 배경 · 흰 카드 · 진한 블루 강조)
- 작은 **아이콘/이미지가 그리드에 반복** ← 유일한 비(非)-CSS 요소

**비율(추정)**: 외곽 여백 ≈ 폭의 6~8% / 그리드 간격 ≈ 4~5% / 번호배지 지름 ≈ 폭의 8~10% / 카드 코너 ≈ 폭의 4~5%. (스샷 눈대중 — 정밀치 아님)

## C. ★ 핵심 결정 포인트 — 아이콘/이미지 어떻게?
정갈형 그리드는 작은 **아이콘/일러스트/사진**에 의존해. 우리는 AI-free라 일러스트를 못 만들어. 3가지 대응:
- **(a) 사용자 이미지 업로드 슬롯** — 그리드 칸에 직접 넣기
- **(b) 이모지/유니코드 심볼** — 무료·즉시, 단 톤이 캐주얼
- **(c) 아이콘 없이 "번호+라벨"만** — 그래도 충분히 정갈, **CSS-only**

→ **추천**: 기본은 **(c)로 CSS-only 정갈형** 확보(P3·P6·P11 등 번호/텍스트 그리드) → 이미지 기능 붙으면 (a) 얹고 → (b)는 옵션.
이러면 "이미지 없어도 규격화된 깔끔한 카드"가 바로 나와서, 네가 싫어한 AI일러스트 의존을 안 해도 됨.

## D. 우선순위 추천 (CSS-only · 高임팩트부터)
이미지 없이 지금 바로 만들 수 있고 임팩트 큰 것:
1. **P1 표지-훅** (전 덱의 얼굴)
2. **P3 번호 그리드** (정갈형의 상징, 아이콘 없이 번호+라벨로)
3. **P13 CTA/마무리**
4. **P14 목차** · **P6 체크리스트** · **P11 스텝** (정보형 핵심)
5. **P7 통계** · **P8 인용** 강화 · **P9 VS** · **P12 한줄강조**
→ P4·P5(아이콘/이미지 필수)는 **이미지 업로드 기능 뒤로**.
