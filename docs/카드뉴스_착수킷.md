## 4. 수확 맵 (Project01-react → 카드뉴스)

| 수확 대상 | 원본 위치 | 처리 |
|---|---|---|

| 드래그·스케일·회전 | `EditorPage.jsx` 253~350 (`initDynamicBlock`) | 훅/유틸로 추출. **MVP는 조작 격하** — 우선 순수 슬롯 렌더, 조작은 후순위 |

**걷어낼 GOI 전용**: 감정 스티커·드래곤 이모티콘(EMOJI_DATA), 친구일기(cheer)·AI템플릿 진입, 일기장 피커(diary-example), 날짜 헤더, BottomNav, 상점, `#6728FF` 보라(→테마 accent 토큰).

## 5. 데이터 모델 (핵심)
```js
// 덱 = 카드 배열. 테마는 덱 전역 1개(일관성 원칙).
deck = {
  themeId: 'editorial',
  ratio: '4:5',
  cards: [
    { id, templateId: 'cover', slots: { title:'', subtitle:'', image:null }, decorations: [] },
    ...
  ]
}
```
- **일관성=카드 레벨(테마 전역), 다양성=덱 간**(설계 SSOT 원칙).
- `decorations` = 나중에 조작 레이어(스티커/자유 텍스트)용, MVP는 빈 배열.

## 6. 템플릿 5종 (슬롯 스펙 — MVP)
| id | 이름 | 슬롯 | 레이아웃 의도 |
|---|---|---|---|
| `cover` | 표지 | title(대), subtitle(소), image?(풀블리드) | 대형 제목, 이미지 있으면 오버레이 |
| `body` | 본문 | heading, body | 제목+문단, 자동 축소 |
| `list` | 리스트 | heading, items[] | 번호/불릿 3~5 |
| `quote` | 인용 | quote, source | 큰 세리프, 따옴표 |
| `stat` | 통계 | number, unit, caption | 초대형 숫자 |

## 7. 테마 토큰 (2~3벌 — 팔레트/폰트는 디자인 시 확정, 지금은 뼈대)
```js
themes = {
  editorial: { bg:'#fff', ink:'#111', accent:'#111',
               fontDisplay:"'General Sans',sans-serif", fontBody:"'Newsreader',serif" },
  mono:      { bg:'#111', ink:'#fff', accent:'#d6ff1e', fontDisplay:"...", fontBody:"..." },
  // + 1벌
}
```
- 퍼스널브랜딩에서 고른 **General Sans / Newsreader / Pretendard** 재사용 가능(서사 일관).
- Shuffle = accent 색상환 + 배경 변주(테마 내 안전범위).

## 8. 빌드 순서 (수직 슬라이스 먼저 = 리스크 조기 제거)
1. 스캐폴드(1~3장) + reset.css + 4:5 고정 캔버스
2. `cover` 템플릿 1종만 데이터→렌더 (하드코딩 텍스트)
3. 슬롯 contenteditable 편집 → 상태 반영
4. 테마 토큰 적용(1벌)
5. **PNG 내보내기 연결(최우선 검증)** — 여기까지가 "된다/안된다" 판가름
6. 덱(여러 카드)+템플릿 스왑, 템플릿 5종 채우기
7. 테마 2~3벌 + Shuffle
8. Tier-1 조작(순서변경) / (여력 시) 레일 위 조작

## 9. 레포 생기면 Claude가 즉시 할 일
1. 스캐폴드 파일 생성(1·2·3장) → `npm install`

3. 수직 슬라이스(8장 1~5단계)까지 만들고 **preview로 실제 빌드/내보내기 검증**
4. 진행상황 이 문서 하단 로그에 기록
