## 1. 클라이언트 피드백 대응 (이번 작업의 큰 축)

**"좌우 여백이 없어 답답하다"** → 무대 전체를 축소해 여백을 만드는 방식으로 해결.

- `js/main.js` 의 `STAGE_MARGIN = 0.04` (화면 폭의 4%, 최소 24 / 최대 120px)
- `sf = (innerWidth - margin*2) / 1920` 로 계산하고 `--stage-margin` 을 CSS 변수로 내려보냄
- 세 개의 스케일 래퍼(`.stage`, `.values-scale`, `.footer-scale`)가 `translateX(var(--stage-margin)) scale(var(--sf))`

**왜 이 방법인가:** `--gutter` 를 키우는 방식은 하드코딩 좌표 53개를 전부 옮겨야 하고
(좌측 기준은 +, 우측 기준은 − 로 방향이 달라 실수 위험이 큼), Figma 시안과 좌표가 어긋나
이후 실측 워크플로가 깨진다. 무대 축소는 **한 줄이면서 정렬을 100% 보존**한다.

⚠️ **여백 도입 시 같이 보정해야 하는 곳** (놓치면 어긋남):
- 헤더 패딩 → `calc(var(--stage-margin) + var(--pad-x) * var(--sf))`
- 히어로 영상 시작 좌표 → `margin + BOX.x * sf`
- 푸터 다크 배경 → `.site-footer` 가 아니라 **`.footer-reveal`** 에 칠해야 화면 끝까지 참

**부작용:** 전체가 6~7% 작아져 12px 라벨이 화면상 10px 아래로 내려감.
여백을 더 키우라는 요구가 오면 **작은 글자만 1~2px 올려 보정**할 것.

## 6. 푸터 등장 방식 변경 (reveal)

본문이 위로 걷히면서 아래 깔린 푸터가 드러나는 방식.

- 푸터를 무대 밖으로 빼 `position: fixed; bottom: 0` (z0), 본문 `.stage-wrap` 은 z1 + **불투명 배경**
- `.footer-space` (= 푸터 높이) 만큼 스크롤 여유를 두어 정확히 다 드러남
- `#contact` 앵커를 `.footer-space` 로 옮김 — **고정된 요소는 스크롤 목적지가 될 수 없음**

⚠️ **3D 오브제를 되살릴 때 충돌한다.** 이 효과는 본문이 불투명해야 성립하는데,
현재 `#hero3d` 캔버스는 `.stage-wrap` 뒤에 있어 가려진다. 되살리려면 캔버스를
`.stage-wrap` **안쪽 맨 뒤**로 옮겨야 한다.

## 8. 인터랙션 조정

**인트로 시퀀스** — 3D 오브제 비활성에 맞춰 대기 시간 제거. 전체 3.6초 → **2.2초**
`0.0s 헤더 → 0.7s THINK(+스튜디오·화살표·십자) → 1.0s MAKE &(+영상 등장·재생) → 1.3s DELIVER`
⚠️ 3D 를 되살리면 `--delay` 들을 hero3d.js 종료 시각(약 1.6s) 뒤로 다시 밀 것.

**프로젝트 부유 효과** — "여백이 좁아 답답하다"는 피드백에 등장 시점을 늦춤
- `FLOAT_START 0.85` : 요소 상단이 화면 높이의 85% 지점에 와야 **비로소 나타나기 시작** (그전엔 투명)
- `FLOAT_SETTLE 0.20` : 이 지점에서 제자리 안착
- `FLOAT_FADE 0.6` : 진행률 60% 에서 페이드인 완료
- 이징은 easeInOutCubic — `pow(1-p,3)` 은 움직임의 87%가 전반에 몰려 "너무 빨리 도착"

## 9. 신설 — 클론코딩 목록 (아코디언 + 실사이트 편입)

`FEATURED PROJECTS` 아래 리스트를 **태그 나열 → 아코디언**으로 교체.

- 행을 누르면 새 창이 아니라 **그 자리에서 아래로 펼쳐진다.** 꺾쇠는 닫힘 ∨ / 열림 ∧ (180° 회전)
- 높이 애니메이션은 `grid-template-rows: 0fr → 1fr` — `max-height` 로 큰 값을 추정하지 않아도
  내용 높이만큼 정확히 열린다
- `<a href>` → `<button aria-expanded>` 로 바꿔 키보드·스크린리더 대응

### 클론 사이트를 저장소에 편입 (`clones/`)
Vercel 에 프로젝트를 따로 만들 필요 없이, **정적 폴더로 함께 배포**한다.

| 경로 | 사이트 | 중점 실습 (코드 확인) |
|---|---|---|
| `clones/03/` | 와이스튜디오 | slick 페이드 슬라이더 + splitting.js 글자 단위 등장 |
| `clones/04/` | 크루 아라모드 | 배경 영상 레이아웃 + 스크롤 구간별 고정/해제 |

- 4개 모두 **절대경로를 쓰지 않아** 하위 폴더로 옮겨도 그대로 동작 (사전 확인함)

  본문의 React·바닐라와 대비되는 것이 오히려 자연스럽다

### 호버 미리보기
행에 마우스를 올리면 **실제 클론 사이트를 iframe 으로 축소해** 커서 옆에 띄운다.

터치 기기(`hover: none`)에서는 만들지 않는다.

### ⚠️ 용량 최적화 (커밋 전 반드시)

  **우측 정렬 요소는 반드시 `right` 로 잡을 것.**
- **⚠️ `syncHeights()` 도입**: 무대 안 내용 높이가 변하면(아코디언 등) 클램프를 다시 재야 한다.
  안 하면 `overflow: hidden` 에 잘린다. 아코디언은 전환 0.4초 동안 매 프레임 호출.
  **앞으로 무대 안에서 높이가 변하는 요소를 추가하면 반드시 이 함수를 호출할 것.**
