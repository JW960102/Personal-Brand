## A. InApp — 카드뉴스 에디터 (먼저 작업)

### A-1. 🔴 설정 화면을 좌측 작업 패널로 (포토샵·피그마 방식)

**지금:** 전체 화면 설정(`GenSetup`) → 생성 → 전체 화면 작업창(`GenWorkspace`).
두 화면이 완전히 갈라져 있고, 작업창은 **카드가 480px 고정이라 좌우가 텅 빈다.**

> "어차피 카드 확대축소 못 하는데 빈 공간이 너무 많아서 촌스러워 보인다"

**바꿀 방향:**
```
┌──────────┬────────────────────────┬─────────┐
│ 설정 패널 │      카드 캔버스        │ 속성 패널│
│ (좌측)    │                        │ (우측)   │
│          │                        │         │
│ 접힘 ◀   │                        │         │
└──────────┴────────────────────────┴─────────┘
   ↑ 생성하면 스르륵 접히고, 버튼으로 다시 펼침
```
- 설정을 **좌측 패널**로 옮긴다 (별도 화면 아님)
- 생성하면 패널이 **접혀 들어가고**, 다시 펼치는 버튼을 남긴다
- 빈 좌측이 패널로 채워져 여백 문제가 같이 해결된다

⚠️ 지금 `GenApp` 은 `deck` 유무로 두 컴포넌트를 갈아 끼운다.
   → 한 화면 안에서 패널 접힘 상태로 바꿔야 하므로 **흐름 자체를 손봐야 한다.**

### A-2. 🔴 폰트 변경 기능이 없다

`src/data/styles.js` 의 세 스타일이 **전부 Pretendard 하나만** 쓴다.
```js
'--font-display': "'Pretendard Variable', Pretendard, sans-serif",
'--font-body':    "'Pretendard Variable', Pretendard, sans-serif",
```
카드뉴스에서 폰트는 톤을 가르는 가장 큰 요소인데 바꿀 수단이 없다.
→ 폰트 선택 UI + 실제 적용까지.

## B. 포폴 사이트

### B-1. 프로젝트 01·02·03 이미지 인터랙션이 너무 빨라 안 보인다

> "어바웃(Works) 페이지 이미지 인터랙션이랑 똑같이 해달라"

**원인 — 두 리빌의 설정이 다르다.**

| | 프로젝트 01~03 (`.curtain`) | Works 카드 (`.work-card-media`) |
|---|---|---|
| 시작 | `inset(92% 0 0 0)` — 8% 보임 | `inset(100% 0 0 0)` — **완전히 가림** |
| 시간 | **1.15s** | **1.8s** |
| 이징 | `cubic-bezier(.16,1,.3,1)` | `cubic-bezier(.22,1,.36,1)` |
| 지연 | 없음 | 카드마다 120ms 스태거 |

시작부터 8%가 보이는 데다 1.15초라 **"이미 있던 이미지"처럼 보인다.**
→ Works 쪽 값(100% 시작 · 1.8s)으로 맞춘다.

### B-2. 어바웃 목차 — 영어 대소문자를 섞어 성의 있게

지금 `.case-h` 에 `text-transform: uppercase` 가 걸려 `TIMELINE` 처럼 전부 대문자로 찍힌다.
→ 대문자 강제를 풀고 단어별로 다듬는다.

### B-3. 어바웃 목차를 아코디언으로

> "바로가기 버튼 말고, 누르면 연혁표가 펼쳐지는 방식은 어떠냐"

지금은 `( 01 )~( 04 )` 를 누르면 해당 섹션으로 **스크롤 이동**한다.
→ 그 자리에서 **펼쳐지도록** 바꾼다. (메인의 클론코딩 아코디언과 같은 방식 재사용 가능)

### B-4. 어바웃 — 제목 고정 + 옆 리스트만 스크롤

지금 `.case-sec` 는 좌 라벨 650px / 우 본문 890px 2단인데, 스크롤하면 **둘 다 같이 올라간다.**
→ 좌측 제목을 `sticky` 로 고정하고 우측 내용만 흐르게.

⚠️ **주의:** `position: sticky` 는 조상에 `overflow` 가 있으면 죽는다.
   `.stage-clamp { overflow: hidden }` 안에 있어서 **그대로는 안 먹는다.**
   (메인의 가치 섹션을 무대 밖으로 빼낸 것과 같은 이유 — 로그 2026-07-31 참조)

### B-5. 영상 화질 개선 — *본인 작업*

브라우저 캡처 화질이 부족해 **반디캠 등 외부 녹화 프로그램으로 다시 촬영** 예정.
새 파일이 나오면 Vercel Blob 업로드 → `index.html` 의 `<source>` URL 교체만 하면 된다.
